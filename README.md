# 🎮 RayLib 2D Games

A collection of 2D game programming experiments and projects developed in **C++ using Raylib**.

This repository was created as a way to learn and practice 2D game development fundamentals, including game loops, player movement, collision detection, rendering, input handling, and other gameplay programming concepts.

## 🚀 Getting Started

### Requirements

To run the projects, you will need:

* Windows
* Visual Studio
* C++ development tools
* Raylib

### Running the Project

1. Clone the repository:

```bash
git clone https://github.com/joaogozzi/RayLib-2D.git
```

2. Open:

```text
Raylib_2D_Games.sln
```

3. Select the desired configuration, such as:

```text
Debug / Release
x64
```

4. Build and run the project from Visual Studio.

## 📚 About Raylib

Raylib is a simple and easy-to-use library designed for learning videogame programming and prototyping. It provides functionality for graphics, input, audio, textures, cameras, and other common game-development features.

Official Raylib resources:

* [Raylib Website](https://www.raylib.com/)
* [Raylib GitHub](https://github.com/raysan5/raylib)
* [Raylib Cheatsheet](https://www.raylib.com/cheatsheet/cheatsheet.html)
